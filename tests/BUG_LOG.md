# 问题登记簿（BUG_LOG）

> 本文件记录 office-clone 开发过程中已修复的问题与当前已知边界。
> 格式：编号｜现象｜根因｜修复｜验证

## 一、已修复（按时间序）

### #1 Windows 中文路径打不开（2026-11-07）
- **现象**：真机打开中文名文档（标书/PRD）报"打开失败"
- **根因**：fopen 按 ANSI 代码页（GBK）解读路径，上层传 UTF-8 → 乱码
- **修复**：新增 `core/PlatformIO`（fopenUtf8：Windows 下 UTF-8→UTF-16 走 _wfopen）
- **验证**：CI 中文路径回归 4 项断言先红后绿

### #2 文字重影/重叠 + 光标乱跑（2026-11-07）
- **现象**：打开文档后文字挤压成一坨，编辑时光标乱跳
- **根因**：QTextLayout 布局忘设行纵向坐标，所有行画在 y=0
- **修复**：逐行 setPosition + 光标用 lineForTextPosition 精确定位
- **验证**：真机截图 OCR 确认修复

### #3 表格不显示（2026-11-07）
- **现象**：WPS 可见表格（如 PRD 两列表）我们完全空白
- **根因**：视图只布局段落，跳过 Table 节点
- **修复**：TableBox 布局（网格+表头底色+单元格文本+列宽按 dxa 比例）
- **验证**：项目章程 8 张表正常渲染

### #4 保存报 cannot create zip（2026-11-07）
- **现象**：编辑后 Ctrl+S 弹"cannot create zip: C:/…/贪吃蛇…docx"
- **根因**：长驻源文件 rb 句柄未关闭，Windows 拒绝对同一文件的 wb 创建
- **修复**：保存前关闭 srcZip → 写入 → 重开；弹窗加指引
- **验证**：真机保存成功

### #5 打开即闪退（2026-11-08，批次B引入）
- **现象**：选中文件打开程序直接关闭（章程/PRD 全崩）
- **根因**：章程含负缩进 left="-425"，uint32 解析爆成 42 亿 → 行宽巨负 → Qt 崩溃
- **修复**：①负缩进 clamp≥0 ②行宽下限 40px 保险丝
- **验证**：缩进值域检查 0 异常；四真实文档冒烟通过
- **教训**：此后每批出包前必跑四文档冒烟

### #6 CI artifact 缺 platforms/qwindows.dll（2026-11-09）
- **现象**：CI 下载的包双击报"找不到 Qt 平台插件"
- **根因**：workflow 上传规则只收 *.exe/*.dll，漏插件子目录
- **修复**：改为上传整个 build/Release 目录

### #7 保存丢失页眉（隐性数据丢失，2026-11-09）
- **现象**：含页眉文档保存后页眉消失（未爆发——开发中发现）
- **根因**：DocxWriter 全量重写但未生成 header/footer 部件
- **修复**：Document.headerFooter 关系收集 + Writer 部件/rels/ContentTypes 保真搬运
- **验证**：保存→重读 header 关系完整
